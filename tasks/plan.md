# 구현 계획: 한일 여행 쇼핑 실속 계산기 (가칭)

- 기준 문서: [SPEC.md](../SPEC.md)
- 작업 상세: [todo.md](todo.md)
- 작성일: 2026-11-05

## 개요

일본에서 쇼핑하는 한국인 여행자가 환급액, 귀국 세금, 최종 실지출을 한 화면에서 확인하는 정적 사이트를 만든다. 틀린 계산이 가장 큰 위험이므로 **규칙 확인과 계산 로직을 UI보다 먼저** 완성한다. 면세 개편 직후의 수요를 놓치지 않도록, 세율 일부가 미확인이어도 출시할 수 있게 설계한다.

## 설계 결정

| 결정 | 이유 |
|---|---|
| 포트폴리오와 분리된 새 저장소 | 배포, 수익화, 이력을 독립적으로 관리한다. |
| Next.js 16 정적 내보내기, React 19, Tailwind 4 | 포트폴리오와 같은 버전대로 학습 비용을 줄인다. |
| 계산 로직은 `src/domain`의 순수 함수 | UI 없이 경계값과 대조 사례를 테스트할 수 있다. |
| 규칙 값은 `src/rules`에 출처, 시행일, 확인일과 함께 저장 | 출처 페이지를 자동 생성하고, 제도 변경 시 한 곳만 고친다. |
| 세금 계산 상태를 `확정`, `기준에 따라 다름`, `계산 불가`로 구분 | 미확인 규칙을 추측하지 않고 화면에 그대로 드러낸다. |
| 입력 상태는 버전이 있는 스키마로 `localStorage`와 URL 해시에 저장 | 서버 없이 저장과 공유를 지원하고, 이전 링크도 안전하게 처리한다. |
| 처음부터 `/ko/` 경로 사용 | 일본어판을 추가해도 주소가 바뀌지 않는다. |

정적 내보내기에서는 서버 리다이렉트를 쓸 수 없어, `/`는 `public/_redirects`와 meta refresh로 `/ko/`로 보낸다. `_redirects` 동작은 Task 16에서 운영 환경으로 확인한다.
